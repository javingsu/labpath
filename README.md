임상병리 채용 공고와 대학원 정보를 한곳에서 보는 개인용 사이트입니다.
**GitHub가 매일 08:23(한국 시간)에 공고를 모아 사이트를 자동으로 갱신**합니다. 서버나 유료 구독은 필요 없습니다.

- 자동 수집(채용): 잡알리오 · 사람인 · 잡코리아 · 이화의료원 · 씨젠의료재단
- 자동 수집(대학원): 연세대 미래캠퍼스 전기·후기 일반전형 일정 · 남서울대 대학원 모집요강·공지 · 서영대 대학원 입학 안내
- 관심 공고 · 지원 현황 · 메모는 각자의 브라우저에만 저장됩니다(저장소에 올라가지 않음).
- 자동 수집이 막힌 출처는 사이트의 **수집 도우미**(북마크)로 보완할 수 있습니다.

## 처음 설정 (약 10분, 한 번만)

### 1. 저장소 만들기
1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **＋** → **New repository**
2. Repository name: `labpath` (원하는 이름 가능)
3. **Public** 선택 → **Create repository**
   > 무료 GitHub Pages는 공개 저장소에서만 됩니다. 공고 자료만 공개되고, 개인 기록은 올라가지 않아요.

### 2. 파일 올리기
1. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
2. 받은 zip을 푼 뒤, **폴더 안의 모든 파일과 폴더**를 브라우저 창에 끌어다 놓습니다.
   (`index.html`, `feed.json`, `README.md`, `collector` 폴더, `.github` 폴더)
3. 아래 **Commit changes**를 누릅니다.

> ⚠️ `.github` 폴더는 숨김 폴더라 끌어다 놓을 때 빠질 수 있어요. 올린 뒤 저장소에 `.github/workflows/update.yml`이 보이지 않으면:
> **Add file → Create new file** → 파일 이름 칸에 `.github/workflows/update.yml` 입력 → zip 안의 같은 파일 내용을 복사해 붙여 넣기 → **Commit changes**

### 3. 사이트 공개 방식 설정
**Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.

### 4. 첫 수집 실행
1. **Actions** 탭 → (처음이면 *I understand my workflows, go ahead and enable them*) 
2. 왼쪽 **랩패스 공고 자동 업데이트** → 오른쪽 **Run workflow** → **Run workflow**
3. 1~2분 뒤 초록 체크가 뜨면 완료. 실행 기록을 열면 사이트 주소가 보입니다:
   `https://<내 GitHub 아이디>.github.io/labpath/`

이제 매일 아침 자동으로 갱신됩니다. 휴대폰에서도 같은 주소로 열 수 있어요(홈 화면에 추가 추천).

## 자주 묻는 것

**기존 관심 공고·메모를 옮기려면?**
예전 사이트에서 왼쪽 아래 **내 데이터 내보내기** → 새 사이트에서 **백업 가져오기**.

**지금 바로 업데이트하려면?**
사이트 상단 안내의 **지금 수집 ↗** 버튼(또는 Actions 탭 → Run workflow). GitHub 로그인 상태여야 합니다.

**수집이 실패했다고 나와요.**
- 사이트의 **정보 출처** 화면에서 어느 출처가 실패했는지 볼 수 있어요. 실패한 출처는 직전 자료를 유지합니다.
- 사람인·잡코리아는 클라우드 서버 접속을 막을 때가 있습니다. 그럴 땐 **자료 업데이트 → 수집 도우미**로 내 브라우저에서 가져오면 됩니다.
- 모든 출처가 실패하면 Actions가 빨간색으로 표시되고 GitHub가 이메일로 알려 줍니다.

**특정 출처를 끄고 싶어요.**
`collector/config.json`에서 해당 출처를 `false`로 바꿔 저장(Commit)하세요.

**자동 실행이 멈췄어요.**
GitHub는 활동이 60일 없는 공개 저장소의 예약 실행을 멈춥니다. 매일 수집 결과가 저장되므로 보통 문제없지만, 멈췄다면 Actions 탭에서 **Enable workflow**를 누르세요.

**예약 시간이 정확하지 않아요.**
GitHub 예약 실행은 몇 분~수십 분 늦을 수 있습니다. 시간을 바꾸려면 `.github/workflows/update.yml`의 `cron` 값을 고치세요(UTC 기준, 한국 시간 −9시간).

## 수집 원칙
- 공개된 검색 결과·채용 게시판만 하루 한 번 읽고, 로그인하거나 접근 제한을 우회하지 않습니다.
- 수집기는 자신을 `LabpathCollector`로 밝힙니다. 사이트가 거절하면 그대로 실패로 기록합니다.
- 최종 지원 조건은 반드시 각 공고 원문에서 확인하세요.
